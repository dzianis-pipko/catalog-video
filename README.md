# Каталог видео

Каталог видео на Next.js с использованием TypeScript, TailwindCSS, TanStack Query.

## Запуск проекта

Для запуска:
node version: v22.16.0

```bash

bun install // yarn install

bun run dev // yarn run dev
```

После этого приложение будет доступно по адресу http://localhost:3000.

## Основные решения

- Использован Next.js (App Router) с TypeScript
- Стилизация компонентов через TailwindCSS
- Управление асинхронными данными через TanStack Query
- Данные получены из локального JSON-файла через Next.js API route
- Присутствует фильтрация по длительности, поиск с дебаунсом и сортировка по дате
- Использована SSR для лучшей производительности и SEO
- Добавлена ленивая загрузка изображений
- Присутствует типобезопасность
